# INACHE SIA — REAL ESTATE

Сайт-визитка агентства недвижимости INACHE SIA, Рига, Латвия. Опыт с 1998 года. Языки: LV / RU / ENG.

Статический сайт: HTML, CSS, JavaScript. Сборка и зависимости не требуются. Главная страница — `index.html`. Стрелки выполнены в SVG. Шрифты Inter и Barlow Condensed загружаются из Google Fonts.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch, затем нужную ветку и папку / (root). Свой домен подключается отдельно, после проверки сайта. Существующий CNAME сохраняет домен inache.lv.
